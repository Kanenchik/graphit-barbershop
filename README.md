# Графит — демо-сайт барбершопа
Демонстрационный проект (React + Vite). Барбершоп вымышленный.

- Ссылка на запись: `src/config.js` (поле BOOKING_URL)
- Услуги, мастера, преимущества: `src/data.js`
- Фото: папка `public/img` (hero.jpg, master-1..3.jpg, work-1..6.jpg)
- Запуск: `npm install`, затем `npm run dev`
